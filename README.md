# HR Analytics Dashboard — Power BI

A portfolio-ready HR analytics dashboard project built for Microsoft Power BI.

## Included

- 500 synthetic employee records
- 6 KPI measures using DAX
- 1 DAX calculated column (`AgeGroup`)
- Interactive report layout with KPI cards and charts
- PBIP + PBIR + TMDL project structure designed for GitHub/source control

## KPIs

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Salary
- Average Age

## Visuals

- Attrition by Department
- Employees by Gender
- Attrition by Job Role
- Average Salary by Department
- Employees by Age Group
- Attrition by Overtime

## Open in Power BI

1. Open Power BI Desktop.
2. Enable **Power BI Project (.pbip)** and **Store reports using enhanced metadata format (PBIR)** under File → Options and settings → Options → Preview features if required by your Desktop version.
3. Open `HR-Analytics-Dashboard.pbip`.
4. If Power BI asks to apply/refresh project changes, accept them.
5. Save the project from Power BI Desktop after it opens successfully.

## GitHub

Commit the entire project folder, including:
- `.pbip`
